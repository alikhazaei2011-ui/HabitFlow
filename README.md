# HabitFlow

A Persian RTL, mobile-first habit tracker PWA built with vanilla HTML, CSS and JavaScript.

## Features in this first version
- Light and dark themes (saved locally)
- Add positive habits and habits to quit
- Daily completion tracking
- Today overview, progress percentage and weekly activity
- LocalStorage persistence
- Installable PWA shell and basic service-worker caching

## Deploy on GitHub Pages
1. Upload all files and folders in this project to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Open the published Pages URL over HTTPS.

## Data note
This version stores data in the current browser on the current device. It does not include accounts, cloud sync or cross-device backup. Clearing browser storage can remove locally saved data.
